Getting started

Install the package:

npm install @waaark/luge

Module usage

import { Luge, Reveal, Browser } from '@waaark/luge'
import '@waaark/luge/css'

const luge = new Luge()
luge.addPlugin('browser', Browser)
luge.addPlugin('reveal', Reveal)
luge.settings({ reveal: { stagger: 0.1 } })
luge.init()
<div data-lg-reveal="fade-to-top">Hello, luge.</div>

Register plugins and configure settings before init(). Register Browser before using luge.browser in settings. The CSS includes built-in reveals, loaders, cursor styling, and Lenis integration rules; include it when using those features, or supply equivalent styles.

init() starts the load lifecycle when the DOM is ready, or on a future ticker update if it is already ready. Register startup listeners before calling it; do not assume plugin elements are initialized on the next line.

Settings

luge.settings(options) merges the supplied values into the current settings. Configure them before initialization; most plugins capture their settings at startup rather than reacting to later changes.

SettingDefaultPurpose
cursor.inertia / cursor.trailLength1 / 10Cursor interpolation and trail length.
intersection.threshold0.3Native IntersectionObserver threshold used by ViewportObserver and Intersection.
lottie.renderer / lottie.subFrame'svg' / trueLottie rendering defaults.
mouse.inertia0.1Mouse interpolation factor.
parallax.inertia0.1Parallax interpolation factor.
preloader.duration0Minimum preloader duration in seconds.
reveal.stagger / reveal.threshold0.1 / 0.15Reveal batch spacing in seconds and scroll-progress threshold.
scroll.inertia / scroll.start / scroll.end0.1 / 1 / 0Scroll animation interpolation and viewport boundaries.
smooth.inertia0.1Retained for compatibility; not consumed by Lenis.
ticker.externalfalseSupply ticks from your own animation loop.
transition.reloadfalseUse full document navigation after the out transition.
credits.showtrueShow the console credit at startup.

Plugins extending Plugin also accept disabled: true; see Disable plugins. Inertia has different meanings across plugins; use the individual plugin reference when tuning it.

The shared plugin attribute parser treats Boolean attributes as enabled when present, including an empty value; only the literal value "false" parses as false. Some activation checks instead use attribute presence directly, including data-lg-smooth and data-lg-reload. Omit an attribute when disabling that behaviour. Omit optional string attributes when unused; a table default of unset means no value is supplied.

Script usage

Copy the release’s dist files to your site:

<link rel="stylesheet" href="/lib/css/luge.css">
<script src="/lib/js/luge.umd.js"></script>

The UMD bundle registers every plugin, initializes automatically, and exposes window.luge. It disables cursor and smooth scrolling on handheld devices, and smooth scrolling on Safari 12 and earlier. Module usage lets you choose these settings explicitly.

Available exports

Luge, Plugin, Preloader, Reveal, Transition, ScrollAnimation, SmoothScroll, Cursor, Intersection, LottiePlayer, MouseAnimation, Parallax, and Browser are named exports.

Moving from beta

The old default import is replaced by explicit construction and plugin registration. Smooth scrolling uses Lenis; the old smooth.inertia setting is not consumed. Use CSS position: sticky for sticky layouts; there is no Sticky plugin in this version.

Luge requires a browser DOM. Import it on the client, not during server rendering. Core services are shared singletons: use one Luge instance per document. See framework integration and known limitations.
