Ticker

The ticker coordinates animation callbacks. Its internal loop targets 60 updates per second; it does not promise a callback on every display refresh.

Usage

const context = {}
const animate = timestamp => { /* timestamp is in milliseconds */ }
luge.ticker.add(animate, context)
luge.ticker.remove(animate, context)
luge.ticker.nextTick(() => { /* one callback on a future tick */ })

add(callback, context) deduplicates matching callback/context pairs. Pass the same pair to remove. nextTick(callback, context) runs once.

External ticker

Configure this before initialization. Forward milliseconds, including when smooth scrolling is registered:

luge.settings({ ticker: { external: true } })
function frame(milliseconds) {
  luge.ticker.tick(milliseconds)
  requestAnimationFrame(frame)
}
requestAnimationFrame(frame)
luge.init()

GSAP’s ticker provides seconds, so convert them:

gsap.ticker.add(seconds => luge.ticker.tick(seconds * 1000))

Use one external ticker owner. Do not simultaneously drive luge from both examples.
