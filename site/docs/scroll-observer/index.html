Scroll observer

The scroll observer is used to observe DOM Elements visibility and progress within the viewport during scroll.

Usage

// Register before luge.init(). Query the current page on every cycle.
luge.lifecycle.add('pageInit', done => {
  const element = document.querySelector('#my-element')
  if (element) {
    element.addEventListener('viewportintersect', event => {
      console.log(event.target.viewportPosition) // under, in, or above
    })
    element.addEventListener('scrollprogress', event => {
      console.log(event.target.scrollProgress) // 0 to 1
    })
    luge.scrollobserver.add(element)
  }
  done()
}, 30)

Properties

Observed elements get two properties:

  • viewportPosition: a string containing the element position in comparison to the viewport. The element can be under, in or above the viewport.
  • scrollProgress: a number containing the element position within the viewport. It varies from 0 when the element is under the viewport (lower in the page) to 1 when the element is above the viewport (higher in the page).

Events

Listen with addEventListener on the observed element; these CustomEvents do not bubble.

  • viewportintersect : emitted when the element gets in or out the viewport.
  • scrollprogress : emitted during scroll, when its position changes or its progress lies between 0 and 1.

Position changes also emit viewportin, viewportabove, or viewportunder, and emit viewportout for an outside position. Unlike ViewportObserver, this service calculates scroll ranges rather than using native IntersectionObserver entries. The end boundary is clipped to the document’s maximum scroll, so progress can reach 1 while the element is still visible at the bottom of the page.

Methods

add(element, start = 1, end = 0, force = false)

Add an element to the observer. start and end are viewport fractions for the scroll boundaries. When the measured start is negative, progress normally begins at 0 at the page origin; force: true instead computes progress from that negative start. The call is positional: pass true as its fourth argument.

ParameterTypeDescription
elementHTMLElementDOM element to observe.

remove(element)

Remove an element from the observer.

ParameterTypeDescription
elementHTMLElementDOM element to remove.

Initialization

Use this service through a single initialized Luge instance. Register page-specific observations in pageInit after the core observers are ready (position 30), and remove your own callbacks when their owner is disposed. See Getting started.
